To make a secret-code treasure hunt, write a chain of clues where each one names the next hiding place, then put every clue into a different code. Decide the route first and write the answers in plain words. After that, turn them into codes with the [Morse Code Converter](/online-tool/text-tools/morse-code-converter), [Reverse Text](/online-tool/text-tools/reverse-text), the [Upside Down Text Generator](/online-tool/text-tools/upside-down-text), the [Strikethrough Text Generator](/online-tool/text-tools/strikethrough-text) and [Flag Explorer](/online-tool/reference-tools/flag-explorer). The [Wheel Spinner](/online-tool/security-generators/wheel-spinner) settles who gets to read each clue. All six are free, need no account and run in your browser, so your answers stay on your device.

The example here is a birthday party at home for six eight-year-olds. There are five clues and a box of prizes next to a bike in the hall. This is the route, with each clue's answer:

| Clue | Code | Answer | Where the next clue is |
| ---- | ---- | ------ | ---------------------- |
| 1 | Morse code | under the sofa | under the sofa |
| 2 | Backwards text | behind the curtain | behind the curtain |
| 3 | Upside-down text | in the shoe box | in the shoe box |
| 4 | Crossed-out decoys | under the blue pillow | under the blue pillow |
| 5 | Flags | BIKE | prizes, next to the bike |

## How do you turn a clue into Morse code?

Open the Morse Code Converter, clear the sample text and type `UNDER THE SOFA`. **Direction** starts on **Detect automatically**, so it translates as you type:

`..- -. -.. . .-. / - .... . / ... --- ..-. .-`

Letters are separated by spaces and words by a slash. Print that line on the first card. To check it, click **⇄ Swap** and the tool decodes it back to `UNDER THE SOFA`. Anything Morse can't represent, such as an accented letter, is listed under the buttons as "Skipped (no Morse code)".

This clue has 11 different letters, so the children only need a small key. Copy those letters from the **Morse alphabet** chart on the same page. Don't hand over the tool itself, since it would solve the clue for them.

You can also play the clue out loud. **Speed** runs from 5 to 40 WPM and starts at 18, where the whole clue takes about 7.3 seconds, too fast for beginners. Slow it to 5 WPM and each dot lasts 0.24 seconds, which stretches the clue to about 26 seconds. Use **▶ Play** for the whole clue, or type just `SOFA` to get a 9.4-second version the children can replay and write down.

## How do you hide a clue in backwards text?

Clue 2 is under the sofa. In Reverse Text, type `behind the curtain` and try the options in the **Reverse** menu. Each one gives a different level of difficulty:

| Option | Result |
| ------ | ------ |
| Every character (backwards text) | `niatruc eht dniheb` |
| Word order in each line | `curtain the behind` |
| Letters in each word | `dniheb eht niatruc` |

**Letters in each word** suits this age group because the words are still in reading order. **Word order in each line** is easier and works for younger children. **Line order** won't change a clue that fits on one line, but it can scramble a clue written over several lines. The result updates as you type, and you can click **Copy** when you have the one you want.

## How do you make a clue you read by turning the page over?

Clue 3 is behind the curtain. In the Upside Down Text Generator, type `in the shoe box` and leave **Flip** on **Upside down (rotate 180°)**:

`xoq ǝoɥs ǝɥʇ uᴉ`

Print it in a large font. To solve it, the children turn the card around and read it normally. The tool swaps each letter for a similar Unicode character and reverses the order. Letters that look the same either way, such as o, s and x, stay as they are.

For a harder version, choose **Upside-down letters, normal order**. That gives `ᴉu ʇɥǝ sɥoǝ qox`, which comes out backwards once you turn the card. To check your work, paste the flipped text back into the box with **Upside down (rotate 180°)** selected and the original comes back.

Some look-alikes depend on the font, so print a test card first.

## How do you use crossed-out text as a decoy?

Clue 4 is in the shoe box, and it gives the children a break from decoding. It lists three places and rules out two:

i̶n̶ ̶t̶h̶e̶ ̶f̶r̶i̶d̶g̶e̶

under the blue pillow

o̶n̶ ̶t̶h̶e̶ ̶s̶t̶a̶i̶r̶s̶

Make the decoys in the Strikethrough Text Generator. Type each one, leave **Style** on strikethrough, and keep **Also mark spaces (one continuous line)** ticked so the line runs through the gaps between words. Copy the results into your document along with the real answer.

The line is a Unicode mark added after each character, so it pastes into documents that have no strikethrough button. A few fonts draw it slightly off-centre, which is another reason to check your test print.

## How can flags spell out the last hiding place?

The card under the pillow has a row of four flags, and the first letter of each country spells the place:

🇧🇷 🇮🇹 🇰🇪 🇪🇬

That's Brazil, Italy, Kenya and Egypt, which spell BIKE. In Flag Explorer, search for each country, click its flag and use the **Flag emoji** copy button. Flag Explorer covers 250 countries and territories, and the search box also takes capitals and ISO codes. Make this clue on a Mac, phone or Linux machine. Windows doesn't draw flag emoji and shows two letters instead (BR, IT, KE, EG), and those letters give the answer away.

The children will need some help to identify the flags, so warm up before the hunt. Press **🎯 Quiz me** for 10 multiple-choice questions. Filtering by **Continent** limits the quiz to that part of the world, so you can pick the continents your clue uses. Each answer also shows the country's capital. Older children can get capitals instead of flags: Brasilia, Rome, Nairobi and Cairo spell the same word once they've found the countries in the compact list.

## How do you decide who reads each clue?

Six children and one clue card can start an argument, so let the wheel choose. Put the six names into the Wheel Spinner's **Entries** box, one per line, and click **Spin (space)**, or press the space bar. When a name comes up, read out the clue with that child, then click the **Remove** button under the result so they can't win again.

After five spins, you've used all five clues and one name is left. The wheel needs at least two entries to spin, so it stops there, and the remaining child gets to open the prize box. The list stays in your browser between visits, so you can set it up the night before. The **Previous winners** list shows who has already had a turn, in case someone disputes it.

## FAQ

### Can children solve Morse code without hearing it?

Yes. The written form uses dots and dashes, with spaces between letters and a slash between words, so all they need is a printed key with the letters in the clue.

### How do I turn upside-down text back to normal?

Paste it into the Upside Down Text Generator with **Upside down (rotate 180°)** selected. The mapping works in both directions, so flipping it again restores the original letters.

### Why do I see letters instead of flags?

Windows has no flag emoji, so it shows the two letters of the ISO code, such as DE for Germany. macOS, iOS, Android and Linux show the flags. The **🎯 Quiz me** button is turned off on those Windows systems because the letters would give the answers away.

### Is the wheel really random?

Yes. The result comes from your browser's cryptographic random generator, and every entry has the same chance whatever its position or length.
