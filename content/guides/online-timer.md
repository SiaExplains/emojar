When an online timer finishes but you don't hear or see anything, the cause is almost always one of four things: the device or tab is muted, notifications are blocked, a system focus mode is hiding them, or the browser slowed down a background tab. The countdown itself rarely goes wrong. A 30-second test run before you rely on a timer for something important catches all four.

## Do a 30-second test first

Before timing anything that matters, like an exam section, medication reminder or something in the oven, set the [Online Timer](/online-tool/date-time-tools/online-timer) to 30 seconds and press **Start**. Then switch to the tab or app you'll actually be using and wait. You should:

1. Hear a short series of beeps.
2. See a notification, if you allowed them and the timer tab was hidden.
3. Find the time display pulsing red when you return, until you press **Dismiss** or **Reset**.

If any of those is missing, one of the fixes below applies.

## Problem 1: No sound

**Check the volume and mute settings.** The alarm is generated by the browser itself, so it follows your device volume. On many phones, the silent or ring switch and focus modes can also mute browser sound.

**Check whether the tab is muted.** Desktop browsers let you mute individual tabs, usually shown as a crossed-out speaker on the tab. Right-click the tab to unmute it.

**Interact with the page first.** Browsers block sound from pages you haven't interacted with. Pressing **Start** counts, so this is only an issue if something unusual happens, such as the page reloading while the timer is set.

**Know what to expect.** The alarm is a short set of beeps, not a continuous ring. If you're away from your desk, a few beeps are easy to miss. The red pulsing display stays until you dismiss it, so you can tell at a glance that time ran out.

## Problem 2: No notification

When you press **Start**, the browser may ask whether this site can show notifications. The timer only sends one when its tab is hidden: if you're looking at the page, the on-screen alert is enough.

- **You clicked Block.** Click the lock or settings icon in the address bar, set Notifications to Allow, and reload the page.
- **Your operating system is blocking the browser.** On Windows and macOS, notifications are allowed per app in system settings. Make sure your browser is enabled.
- **A focus mode is on.** Do Not Disturb, Focus and similar modes hold notifications silently.
- **You're on an iPhone or iPad.** Safari doesn't support web notifications for ordinary web pages. Keep the tab visible, or rely on the sound.

## Problem 3: The alert came late in a background tab

The timer counts down to a fixed end time, so the remaining time it shows is always correct. Background tabs are a different matter: to save battery, browsers slow down the code that runs in pages you aren't looking at, and some slow it down further the longer a tab stays hidden. That can delay the moment the timer notices it has finished, and therefore the alarm.

For alerts that need to arrive on the second:

- Keep the timer tab visible, for example in its own window beside your work.
- Don't let your laptop sleep. A sleeping computer doesn't run any timers.
- Keep an eye on the browser tab title. While the timer runs, it shows the remaining time, so you can glance at it from any other tab.

## Problem 4: The timer didn't start, or reset itself

- **All fields are zero.** If hours, minutes and seconds are all 0, Start does nothing.
- **You edited a field.** Changing the hours, minutes or seconds discards any paused time, so the next Start uses the new values.
- **The page was closed or reloaded.** The timer lives in the open page. Closing it, or a phone browser unloading it in the background, stops the countdown.

## Setting a timer, step by step

1. Click a preset (**1 min**, **3 min**, **5 min**, **10 min**, **15 min**, **20 min**, **30 min**, **45 min** or **1 hour**), or type **Hours**, **Minutes** and **Seconds**. Up to 99 hours is supported.
2. Press **Start**, or the space bar. The ring around the time fills as the countdown progresses.
3. While it runs, use **Pause**, or **+1 min** to add a minute without restarting.
4. When it ends, press **Dismiss** to stop the visual alert, or **Reset** to set it up again.

The display rounds up, so it never shows 00:00 while time is still left.

## When a browser timer isn't the right tool

For anything safety-critical, such as medication timing or cooking with no one in the kitchen, use a device alarm that works when the browser is closed and the screen is off. A browser timer is ideal when you're at your computer, working in other tabs, and want something quick that needs no app or sign-up.

## FAQ

### Can I run two timers at once?

Yes. Open the timer in a second tab. Each tab runs its own countdown, and each shows its own time in its tab title.

### Will the alarm work if my screen locks?

On desktop, usually yes, as long as the computer doesn't go to sleep. On phones, a locked screen often suspends the page, so don't count on it.

### Is there a way to make the alarm louder?

The alarm uses your system volume. Turn it up, or connect speakers.
